# HEIB12 — Smart & Analytical Testing Platform

منصة اختبارات ذكية وتحليلية متعددة الفئات والتخصصات (طلاب المدارس، الأطفال، الجامعيون والدكاترة، المحامون، المهندسون، ميكانيكيو السيارات، البيطريون، ومحاسبو البنوك) مع مؤشر ذكاء تقديري، احتفال تفاعلي للناجحين والمتفوقين، وتنزيل تقرير مفصل.

## Key Features
- اختبارات متنوعة حسب الفئة والتخصص المهني والأكاديمي.
- حساب مؤشر الذكاء التقديري (IQ Index) وعرض المعدل والنسبة المئوية.
- تفصيل كامل للأداء حسب المحاور مع مراجعة الأسئلة والتعليلات.
- إمكانية تنزيل تقرير النتيجة والتفصيل كملف.
- دعم متعدد اللغات وواجهة سريعة مباشرة في المتصفح.

## Usage
افتح الرابط المباشر أعلاه، اختر الفئة أو التخصص المناسب، ابدأ الاختبار، ثم استعرض أو نزّل تقريرك الكامل عند الانتهاء.
